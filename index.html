How the hybrid works

1 · On-device

Firebase AI Logic's hybrid mode (PREFER_ON_DEVICE) routes the instant pass to Gemini Nano through Chrome's Prompt API. Private by architecture, works offline, costs nothing — and every response carries an inferenceSource stamp so this page can prove which model answered.

2 · In-cloud

Deep analysis runs on a cloud Gemini model (ONLY_IN_CLOUD) with a JSON response schema: action items, decisions, risks and flashcards come back as data, not prose. If on-device is unavailable, even the instant pass falls back here — labelled as cloud, never disguised.

3 · Protected

Firebase App Check guards the AI Logic endpoints (debug-token provider in this build, reCAPTCHA-ready). The analysis engine is Firebase AI Logic end to end — no API keys in the page, no third-party AI calls.

Built with Firebase AI Logic (Web SDK 13.0.0) · Gemini Nano via Chrome Prompt API · Gemini in the cloud · App Check
