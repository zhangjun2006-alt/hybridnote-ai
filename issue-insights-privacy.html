Issue Insights — Privacy Policy

Last updated: November 21, 2026

Issue Insights is a Jira Cloud app built with Atlassian Forge. It adds an issue panel that analyzes the issue you are viewing — its description, subtasks, and status — and shows completeness checks, risk signals, and suggested next actions.

What data the app accesses

The app reads the content of the Jira issue you open its panel on (issue fields, subtasks, and comments counts) using the read:jira-work permission. It accesses this data only in direct response to you opening the panel.

What data the app collects, stores, or sends

None. All analysis runs locally inside Atlassian Forge at request time. The app:

  • does not store any issue data, user data, or analytics;
  • does not send data to any external server (no egress);
  • does not use cookies, tracking, or third-party services;
  • does not collect personal data of any kind.

Because nothing is stored or transmitted, there is nothing to delete, export, or breach.
